# Gráfica Kriar

Site estático com Tailwind CSS.

## Publicar na Vercel

1. Extraia este projeto.
2. Envie os arquivos a um repositório Git e importe o repositório na Vercel, ou execute `npx vercel --prod` nesta pasta.
3. A configuração está em `vercel.json`: preset Other, instalação `npm ci`, build `npm run build`, pasta publicada `dist`.

## Desenvolvimento

- `npm ci`
- `npm run build`

O site já inclui uma cópia compilada em `dist`. As imagens, o CSS e o JavaScript estão incluídos. O formulário gera um resumo local; envio por WhatsApp ou e-mail ainda não foi integrado.
